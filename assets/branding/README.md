# Branding assets

| File | Purpose |
| --- | --- |
| `logo.svg` | iSplit mark, matching the favicon and navbar logo. Use for the README, slides, or press. |
| `social-preview.png` | 1280 × 640 social preview card for GitHub, X/Twitter, and chat unfurls. |

The social preview is not picked up automatically. To set it on GitHub:

1. Open the repository → **Settings** → **General**.
2. Under **Social preview**, click **Edit** → **Upload an image**.
3. Choose `assets/branding/social-preview.png`.

Brand colours used across the app and assets:

| Token | Hex |
| --- | --- |
| Indigo | `#6366F1` |
| Cyan | `#06B6D4` |
| Violet | `#8B5CF6` |
| Ink / background | `#0A0F22` |
| Surface text | `#F8FAFC` |

The logo is a simple mark: a rounded gradient square split into four white tiles with a dashed centre line. Keep clear space around it of at least one tile width, and do not recolour the white tiles.
