# Changelog

All notable changes to iSplit are documented here.

The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this project intends to use [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## Unreleased

### Added

- Repository documentation: contributing guide, security policy, code of conduct, changelog, issue forms, and pull request template.
- Branding assets, README screenshots, and a social preview card.

## 1.0.0 - 2026-11-20

### Added

- Client-side image and PDF upload with drag & drop, file picker, and PDF page selection.
- A0–A6, Letter, Legal, Tabloid, and custom paper sizes with mm/cm/in units and portrait/landscape orientation.
- Segments, manual rows × columns, and auto-from-poster-size grid modes.
- Zoom, pan, rotate, and percentage crop controls, including Ctrl/Cmd + wheel zoom and drag-to-pan in the preview.
- Page margin, gap, overlap, tile borders, crop marks, cut guides, and tile numbers.
- Click-to-include/exclude tile selection in the live preview.
- Multi-page PDF export for all tiles or selected tiles, with configurable DPI and JPEG quality.
- Print support with correct page sizing and optional removal of tile marks from printed output.
- Light/dark themes, persisted preferences via `localStorage`, responsive layout, tooltips, and keyboard-accessible controls.
- About & Demo and From the Creator dialogs.
